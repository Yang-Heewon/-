# 실험 2a 프로토콜 — 배포형 estimator 검증 (단계별 절차와 각 단계의 의미)

> 2026-08-17 작성. 질문: **"전체 KV 없이, 남긴 조각만 갖고도 '이 질문은 못 푼다'를
> 답하기 전에 알 수 있는가?"** 이것이 통과되어야 하이브리드 방법(아이디어 4)이
> '제안'에서 '배포 가능한 방법'이 된다. 실행: H100 컨테이너, ~6 GPU시간 + 분석 반나절.

## 단계 0. 준비물 확인 (이미 있음 — 새 실험 아님)

| 준비물 | 출처 | 상태 |
|---|---|---|
| 정답지: (기억, 질문)별 실제 정답/오답 수천 건 | 교차·held-out 실험 로그 (Qwen2.5·Qwen3 × GUI·자연) | ✅ |
| 부분집합 재구성기 (원본 실험과 비트 단위 일치) | coverage_probe (UNION 크기 4/4 일치 검증됨) | ✅ |
| 비교 기준: 반칙 coverage의 AUROC 0.72~0.85 | 결과 18 | ✅ |

**의미**: 2a는 새 상황을 만드는 실험이 아니라, 이미 벌어진 수천 번의 만남을
재방문하며 "그때 실전 신호로도 결과를 내다볼 수 있었는가"를 후향적으로 채점하는
실험이다. 정답지가 고정되어 있으므로 신호끼리 공정 비교가 된다.

## 단계 1. 신호 수집 (GPU 쓰는 유일한 단계)

각 (이미지, 부분집합 S, 평가 질문 q)에 대해 **실전과 동일한 조건**을 재현한다:
남긴 토큰만 보이는 4D 마스크 상태에서 질문 q를 prefill (기존 실험과 같은 경로).
그 forward 하나에서 다음을 추출한다 — **추가 forward 0회**:

| 신호 | 계산 | 정규화 (도메인 간 눈금 통일) |
|---|---|---|
| A1 절대 attention | 질문 토큰들이 보관 시각 토큰에 준 attention 총량 (전 층 평균) | 질문 토큰 수로 나눔 |
| A2 집중도 | 보관 시각 토큰 위 attention 분포의 엔트로피 | ÷ log(보관 토큰 수) → 0~1 |
| A3 sink 쏠림 | 질문 attention 중 문장 앞 sink 토큰(4개)으로 간 비율 | 이미 비율 (0~1) |
| A4 답 확신도 | 첫 답 토큰의 top1−top2 logit 차 | 그대로 (후보 중 유일한 사후형) |
| (기준) 반칙 coverage | 전체 KV로 계산한 비율 — 상한 비교용 | 결과 18과 동일 |

추가로 **후보 5(자기 보정)용 기준점**: 같은 이미지의 에피소드 질문(q0)에 대해
A1~A4를 계산해 저장 — "이 이미지에서 잘 커버된 질문은 이 정도 점수가 나온다"의 표본.

**의미**: 실전 배포에서 estimator가 보게 될 것과 정확히 같은 정보만으로 점수를
만든다. 여기서 전체-KV 정보가 새어들면(예: 정규화 분모에 지워진 토큰 수 사용)
실험 전체가 무효 — 각 신호의 입력이 "보관 조각 + 질문"뿐인지가 유일한 청렴 조건.

## 단계 2. 판별력 채점 — 관문 1

신호별·도메인별·예산별로 AUROC 계산 (정답 만남이 오답 만남보다 점수가 높을 확률;
FULL 정답 표본 조건부, 이미지 cluster bootstrap 95% CI — 기존 규칙 그대로).

| 결과 | 판정 |
|---|---|
| 최고 신호 AUROC ≥ 0.70 | 통과 → 단계 3 진행 |
| 0.60 ~ 0.70 | 부분 통과 → 신호 조합(단순 로지스틱)으로 재시도 후 판정 |
| < 0.60 | 실패 → 논문 §3을 "이미지로 보관하라"(P2) 프레임으로 전환 |

**의미**: "실패의 정보가 실전에서 접근 가능한 값들에 들어 있는가"의 존재 판정.
반칙 coverage(0.75~0.85)와의 격차 = 지워진 토큰의 정보가 판별에 기여하던 몫.
A1은 반칙 점수의 분자와 동일하므로, 실패한다면 "분모가 판별의 핵심이었다"는
그 자체로 보고 가치가 있는 발견이 된다.

## 단계 3. 임계값 교차 보정 — 관문 2 ("한 번 보정으로 끝"의 검증)

1. GUI 절반 화면에서 임계값 τ를 보정 (폴백 40%가 되는 지점, 결과 18과 정합)
2. 그 τ를 **동결**한 채 적용: GUI 나머지 절반 / 자연(GQA) / 다른 모델(Qwen3 로그)
3. 각 대상에서 정확도-폴백 곡선이 보정 원점 대비 얼마나 무너지는지 기록

| 결과 | 의미 |
|---|---|
| 곡선 유지 (정확도 손실 <3%p) | "보정 1회로 어디서든" — 논문의 실용성 문장 확보 |
| 도메인 건너며 무너짐 | 단계 4(자기 보정)가 구원하는지 확인 |
| 그래도 무너짐 | "도메인당 보정 1회 필요"로 주장을 정직하게 한정 |

**의미**: AUROC는 순위 품질이라 임계값과 무관하다. 배포의 실제 질문은 "숫자 하나를
정해두고 낯선 입력에 그대로 써도 되는가"이고, 이 단계가 그것만 따로 잰다.

## 단계 4. 자기 보정 변형 — 후보 5 (agent 배포형)

절대 점수 대신 **상대 점수** score(q)/score(q0_기준점) 로 단계 2·3을 반복.
기준점은 write 시점에 공짜로 계산되어 기억 옆에 저장된다는 설정 (몇 바이트).

**의미**: 보정 단위를 도메인에서 **기억 항목 하나**로 내리는 것. 통과하면
"에이전트가 낯선 도메인을 만나도 별도 보정 없이 작동"이 성립 — cross-domain
agent 요구사항에 대한 직접 답. (안전판: 어느 단계에서든 임계값이 틀렸을 때의
최악은 오답이 아니라 불필요한 재읽기 — 폴백 경로는 항상 정확하다.)

## 단계 5. 실용 곡선 재작성 — 관문 3 (논문 §4 대표 그림)

통과한 최고 신호로 결과 18·19의 표를 다시 그린다:
폴백 비율 0/20/40/60% × (실전 신호 하이브리드 vs 반칙 coverage 상한 vs 무작위 폴백),
그리고 결과 19의 경로 비용을 결합한 정확도-지연 곡선.

**의미**: "40% 재읽기로 격차 62% 회수"가 반칙 없이도 성립하는지 — 논문이
독자에게 파는 최종 수치. 반칙 곡선과의 간격이 "남은 개선 여지"로 함께 보고된다.

## 청렴 규칙 (기존 프로토콜 상속)

채점은 FULL 정답 표본 조건부 / CI는 이미지 cluster bootstrap / 부분집합·seed는
원본 실험과 결정적 일치 / 신호 입력은 보관 조각+질문만 (전체-KV 누출 금지) /
Qwen3 로그는 임계값 이전 시험에만 사용 (보정에 사용 금지).
