## 0. 논문 한 문장

> 시각 기억(KV 캐시)을 압축해 재사용할 때의 실패는 **저장 시점에는 예측 불가능하지만**
> (어떤 선택 규칙도 천장과 28~55%p 격차 — 우리가 3도메인×2모델에서 증명),
> **읽기 시점에는 감지 가능하다** (실패가 근거 이동에 단조 비례하므로, 질문 도착 순간
> 커버리지를 재면 AUROC 0.72~0.85) — 그 결과 같은 압축률에서
> 조용한 실패 0.55가 관리된 성공 0.94로 바뀐다.

핵심 발상의 이동: **예측 문제 → 측정 문제.**
write 시점의 "미래 질문에 뭐가 필요할까"는 정보가 없어 원리적으로 불가능하다.
read 시점에는 질문이 도착해 미래가 현재가 되므로, "지금 남은 조각으로 이 질문이
풀리는가"를 싸게 잴 수 있다. 판정 시점을 옮기는 것이 방법의 전부다.

## 0.5 방향 선언 (2026-08-18 확정 — 이후 변경은 이 절을 갱신하며)

**이 논문(ICLR 2027)의 정체**: 진단이 이끄는 시스템 논문.
무게 배분 = 실패 지도(§2) 60% : 방법(§3–4) 40%.

**확정된 방법 = 3단 사다리** (각 단계가 "싸게 시도 → 검증 → 승급"의 반복):
```text
1단  검증된 초안 재사용: 과거 답(텍스트, 모델독립)을 보관 KV 위에서
     forward 1회로 병렬 검증, greedy 일치 시 즉시 반환      ~0.06s (spec-dec 메커니즘)
2단  보관 KV로 생성 + 첫 토큰 확신도(a4) 게이트              ~0.98s (결과 21로 검증됨)
3단  원본 이미지 재읽기 (완전 경로)                          ~2.18s (정확도 보장)
```
근거 사슬: 예측 불가(결과 15·16·20) → 감지 가능(18·21) → 폴백은 공짜 보관+빠른 로드
(19+부록) → 초안 재사용은 반복 질문 무대에서 순차 생성을 병렬 검증으로 대체(검증 중).

**이번 논문에서 뺀 것 (후속 논문 큐 — 뺀 이유는 검증 깊이 확보)**:
커버리지-위험 submodular 선택(단조 법칙→목적함수, 3체제 통일 후보) ·
자기 생성 질문 앙상블(아이디어 5) · 층별 예산(아이디어 1) · 학습된 탐지기 ·
**다중 경험 합성(M5)**: 여러 화면을 한 질문에 합쳐 넣는 긴 컨텍스트 상황 —
KV 이어붙이기의 위치·문맥 결합 실패(CacheBlend의 시각판)라는 별개 실패 모드가
있어 분리. 확장 경로는 명시: 검색으로 화면 선별 → 화면별 estimator 판정 →
부족분만 재읽기 + 화면 간 추론은 텍스트 에피소드 층 담당. 한계절에 서술.

**novelty 방어선**: 선택적 예측(selective prediction)·시맨틱 답 캐시(GPTCache류)·
self-speculative 계열을 §5에서 선제 인용하고, 우리 위치 = "그 메커니즘들이 압축된
시각 기억 설정에서 성립함의 첫 증명 + 성립 이유(단조 법칙) + 캐스케이드 통합 +
보증(greedy 동일성)"으로 한정. 과잉 주장 금지: "예측 불가"는 우리 실험 범위 내 증명.

## 1. Motivation 절 — 정확한 구성 (측정 불가능한 주장 금지)

"에이전트는 같은 화면을 다시 만난다"를 **측정하려 하지 않는다** (재방문율은 서비스
종속 통계라 어떤 데이터셋 수치도 일반화 불가). 대신 세 발로 세운다:

**문단 1 — 재사용은 실재한다 (업계 증거, 인용으로 해결).**
prefix/prompt caching은 이미 상용 기능이다(vLLM prefix caching, SGLang
RadixAttention, 상용 API의 유료 prompt caching). 업계가 "같은 앞부분을 반복해서
만나는 워크로드"에 이미 돈을 걸었다 — 재사용의 규모는 우리가 증명할 필요가 없다.

**문단 2 — 그런데 저 시스템들은 전부-보관 아니면 전부-폐기다.**
KV를 통째로 저장하고 LRU로 통째로 버린다. 화면 한 장의 KV는 67MB(실측)라
통째 보관은 스케일하지 않는다. 자연스러운 다음 단계는 "일부만 남기기"인데,
**일부만 남긴 캐시가 미래 질문 앞에서 어떻게 행동하는지는 아무도 재지 않았다.**
기존 KV 압축 연구는 전부 "같은 질문을 다시 물을 때"로 검증한다 — 재사용의 현실은
"다음 질문을 모른다"인데도.

**문단 3 — 재사용이 구조적으로 보장되는 무대에서 실험한다.**
멀티턴 문서/화면 QA(한 이미지에 질문이 이어지는 상황)에서는 후속 질문이 같은
이미지를 때리는 것이 확률이 아니라 구조다. 우리 실험 설정(이미지 1장 × 질문 5~8개)이
정확히 이 워크로드다. 그 밖의 워크로드에 대한 이득은 재사용률 r의 손익분기 곡선으로
조건부 제시한다(결과 19) — 캐시 논문의 표준 화법.

**예상 반박과 준비된 답**:
- "이미지를 다시 읽으면 되잖아" → 맞다, 그래서 우리 방법은 이미지를 버리지 않는다
  (보관은 KV의 1/27이라 공짜). KV 조각의 존재 이유는 바이트가 아니라
  **재계산 시간(TTFT 20배, 실측)**이다. 이 정직함이 P2류 반박을 선제 흡수한다.
- "재사용률이 낮으면?" → 손익분기 곡선으로 조건부 답변. 임계 r 이하면 이미지만
  보관하는 것이 우리 방법의 자연스러운 축퇴(estimator가 항상 폴백 선택).

## 2. 이야기 구조 (절 설계)

```text
§1 서론      : 위 motivation 3문단 + 한 문장 기여
§2 실패 지도 : (진단 파트 — novelty의 '속')
   2.1 용량은 충분하다        — s1 5%로 0.90~0.99          [결과 3·7]
   2.2 선택은 원리적으로 막혔다 — 7규칙 전패, 천장과 28~55%p  [결과 15·16·20]
   2.3 실패의 법칙            — 근거 거리 단조, 3도메인×2모델 [결과 13·16·20]
   2.4 도메인 3체제           — 고정 정책의 불가능성          [결과 14~17]
§3 방법      : (novelty의 '겉') — 판정 시점의 이동, 3단 사다리
   3.1 2층 기억: 이미지 아카이브(완전성) + KV 캐시(속도)      [아이디어 4]
   3.2 1단 — 검증된 초안 재사용 (spec-dec 메커니즘, 보증 포함) [아이디어 3, 검증 중]
   3.3 2단 — 확신도 게이트 (a4, 사후 검증형이 사전형·반칙 상한을 이김) [결과 21]
   3.4 훈련 불필요·추가 forward 0·임계값 1개 이전 가능 — wrapper 성질
§4 평가      : 감지력(AUROC) → 정확도-비용 곡선 → 끝-끝 파이프라인
              vs 항상-이미지 / 항상-KV / KVzip류(원저 구현)    [결과 18·19 + 3단계]
§5 관련 연구 : 선택 축(KVzip·H2O·SnapKV·GUI-KV) vs 우리의 감지 축;
              인접 정신(캐스케이드 이관, speculative 검증)은 인용하되
              시각 KV 압축에서 이 축은 공백임을 명시
```

## 3. Novelty 주장 (2겹 구조와 방어선)

- **겉 (방법)**: KV 압축에 "read-time 충분성 감지"라는 새 축. 조용한 실패 →
  감지된 실패 + 저렴한 복구. 선택기 불문 wrapper(어떤 압축 위에도 얹힘 —
  6종 부분집합 혼합에서 AUROC 0.85로 이미 확인).
- **속 (진단)**: 감지가 왜 가능한지의 원리 — 실패가 근거 이동에 단조 비례한다는
  법칙과, 선택 축이 원리적으로 막혔다는 증명. 이것이 없으면 방법은 트릭이다.
- **방어선**: "예측 불가"는 우리 데이터 안에서의 증명(7규칙×3도메인×2모델)으로
  한정해 주장. 절대적 불가능성 정리가 아님을 명시해 과잉 주장 공격을 차단.
