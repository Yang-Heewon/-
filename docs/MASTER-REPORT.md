# 연구 종합 보고 — 시각 기억 재사용은 어디서, 왜 실패하는가

> 작성: 2026-08-16 · 지위: **파일럿(smoke) 단계 완료 보고** — 수치는 모두 파일럿이며
> 동결 프로토콜 본실험(discovery)으로 승격 전이다. 상세 실험별 서술은
> [FINDINGS.md](FINDINGS.md)(결과 0~17), 실험 설계는 [PLAN.md](../PLAN.md) 참조.

## 1. 한 문장 요약

> 시각 기억(이미지를 읽을 때 생기는 내부 중간 계산 결과 = KV 캐시)을 일부만 남기고
> 지웠다가 나중에 재사용하는 것의 병목은, **저장 용량도 선택 알고리즘도 아니라
> "미래 질문의 근거가 어디일지 저장 시점에 예측되지 않는다"는 사실**이며, 이 실패는
> 세 도메인(문서·GUI·자연 사진)에서 공통이되 드러나는 방식은 도메인의 근거 분포에
> 따라 세 가지 체제로 갈린다.

## 2. 실험이 흉내 내는 상황과 규칙

```text
[어제] 에이전트가 이미지 하나를 처리했다. 이미지를 읽으면 시각 토큰마다
       KV(중간 계산 결과)가 생긴다. 전부 저장하긴 비싸니 5~20%만 남기고 지운다.
       → 이때 내일 무슨 질문이 올지 모른다. (질문 도착 전 삭제 = V2 규칙)
[오늘] 같은 이미지에 대한 새 질문. 남긴 조각만으로 답해야 한다. 원본 이미지는 없다.
```

- **채점**: "압축 안 했으면 맞혔을 문제"에서 압축 후에도 맞히는 비율 = **유지율**
  (FULL 정답 표본 조건부). 신뢰구간은 이미지 단위 cluster bootstrap 95%.
- **반칙 참조선 s1**: 평가 질문 자신을 보고 남길 토큰을 고르는 조건. 현실에선
  불가능하며 성능 천장을 재는 용도.

## 4. 결과 — 네 막

### 1막. 이 측정은 믿을 수 있다 (M0–M1)

- KV를 직렬화→저장→복원→이어쓰기 해도 예측 40/40 동일, 지표 오차는 잡음 수준.
- 압축하지 않으면 아무 문제 없다: FULL 저장 재사용 EM 1.00. 위치 offset +2048에도 강건.
- 질문 KV를 같이 저장하는 실수(V1)는 점수를 4배 부풀린다(0.50 vs 0.12) — 전 실험 V2 강제.

### 2막. 압축의 실패는 "예측 불가능성" 한 곳으로 수렴한다 (문서, M2–M3)

1. **용량은 충분**: 질문을 알면 5%만 남겨도 0.84~0.92, 20%면 0.99. 좋은 부분집합은 존재한다.
2. **저장 시점엔 아무도 못 고른다**: 최고 대리 지표(s5)가 20%에서 0.61 — 천장과 **38%p** 격차.
3. **한 질문용 집합의 재사용은 붕괴**: 같은 질문 0.99 → 다른 질문 0.59 (40%p 추락).
   텍스트 LLM의 KVzip 붕괴(35%p)와 같은 현상을 시각에서 통제 재현.
4. **질문을 3개 겪어도 미래는 못 덮는다**: 3질문 합집합이 본 질문은 0.99, 안 본 질문은
   무작위와 동일(0.14@9%) — 과거 질문에 과적합.
5. **원인은 근거 이동**: 유지율이 근거 중심거리에 단조 감소(0.765→0.307@5%,
   가까움−멂 +30.6%p [19.2, 42.2]).

### 3막. 세 도메인, 세 체제 (GUI·자연 확장)

| | 문서(DocVQA) | GUI(ScreenQA) | 자연(GQA) |
|---|---|---|---|
| 자기 재현−전이 (5%) | ~40%p | ~57%p | +23.0%p [17.1, 29.3] |
| held-out: pool−random | 0%p (과적합) | **+21.1%p [13.2, 29.2]** | +5.9%p (유의하지 않음) |
| random 바닥 (~8–10%) | 0.14 | 0.34 | **0.70** |
| 사다리 승자 (write-time) | **s5**(범용) 0.611 | **h2o**(이력) 0.725, s5는 random −11.2%p | **없음** — 전부 random 수준 |
| 근거 거리 단조 법칙 | ✓ | ✓ | ✓ (T2 0.885/partial 0.714/T3 0.529) |
| 천장(s1)과의 격차 (5%) | +38%p | +54.5%p [49.3, 59.7] | +28.4%p [21.2, 35.6] |

- **체제 해석**: 문서 = 근거 분산·중복 없음 → 범용 중요도가 최선이지만 pool은 과적합.
  GUI = 근거가 소수 정보 영역에 집중 → 과거 이력이 최선, 범용 신호는 역효과.
  자연 = 장면 중복성 높음 → 무엇을 남겨도 비슷, 선택 경쟁 자체가 무의미.
- **공통**: 어떤 체제에서도 단조 법칙이 성립하고 천장과의 격차는 크다 — P1의 일반성.

### 4막. 검증 두 건 + 진행 중 한 건

- **언어 편향 점검(NO-MEM)**: 이미지 없이 질문만 주면 문서 0.011 / GUI 0.043 /
  자연 0.187 (FULL 정답 조건부). 자연의 random 바닥 0.70 중 찍기는 최대 19%p —
  중복성 해석 유지 (GQA 수치엔 이 상한을 병기).
- **집중도의 연속 법칙**: GUI 안에서 근거 분산이 큰 화면일수록 pool 가치가 낮다 —
  Spearman −0.279 [−0.428, −0.122] (독립 표본 중복성 통제, 128장). 도메인 3점
  일화가 이미지 수준 법칙으로 승격. (같은 표본을 예측변수·결과에 겹쳐 쓰면 −0.6짜리
  가짜 상관이 나온다는 통계 함정도 발견·기록.)
- **커버리지 감지기 — 성공 (결과 18)**: 새 질문의 attention이 남긴 집합에 떨어지는
  비중(coverage)이 정답/오답을 AUROC 0.72~0.85로 가려낸다 (배치 상황 GUI
  0.786 [0.718, 0.848]). "coverage 낮은 질문만 이미지 재읽기" 하이브리드는 GUI에서
  40% 폴백으로 격차의 62% 회수(0.546→0.827) — 모든 폴백 비율에서 무작위 폴백을
  지배. 압축의 범용성은 불가능해도 **정책의 범용성**은 성립 가능 → Phase 2 뼈대.

## 5. 결론 — 논문 방향 P1의 현재 성립 상태

| P1 조항 | 증거 (전부 파일럿) |
|---|---|
| 좋은 부분집합 존재 (capacity gap ≤5%p) | s1 0.99@20%, 교환 탐색 0.92@5% — 존재 증명 |
| 저장 시점 방법이 ≥15%p 잃음 | 문서 38%p / GUI 54.5%p / 자연 28.4%p |
| 손실이 relevance 축에 귀속 | 단조 법칙 3도메인 재현 + held-out 과적합 |
| 독립 모델·데이터 재현 | 데이터 3도메인 완료 / **모델은 Qwen2.5-VL 1개 (미완)** |

추가 기여 후보: **도메인 3체제** (고정 압축 정책의 불가능성 → 정책 수준 범용성),
selector 역전(s5↔h2o), GUI 이미지 수준 연속 법칙.
