# 연구 종합 보고 — 시각 기억 재사용: 실패의 지도와 감지-폴백 방법

> 갱신: 2026-08-18 · 지위: **파일럿(smoke) 전체 완료** — 진단(결과 1~17), 방법 성립

## 1. 한 문장 요약

> 시각 기억(KV 캐시)을 일부만 남기는 압축의 실패는 **저장 시점에는 예측 불가능**
> (7개 선택 규칙 × 3도메인 × 2모델 전패, 천장과 28~56%p)하지만 **읽기 시점에는
> 감지 가능**(첫 답 토큰의 확신도가 AUROC 0.73~0.81)하며, 감지-폴백 정책은 같은
> 압축률에서 조용한 실패 0.55를 관리된 성공 0.84~0.96으로 바꾼다.

## 2. 실험 규칙 (전 결과 공통)

- **V2 규칙**: 질문 도착 전에 남길 토큰을 고른다 (미래 질문 열람 금지).
  질문을 보고 고르는 s1은 천장 측정용 반칙 참조선.
- **유지율**: 압축 없이(FULL) 맞힌 표본에서, 압축 후에도 맞는 비율 (조건부).
- **신뢰구간**: 이미지 단위 cluster bootstrap 95%.
- 모델: Qwen2.5-VL-7B + Qwen3-VL-8B (fp16/eager, V100·A100), 도메인:
  문서(DocVQA 32) · GUI(ScreenQA 150) · 자연(GQA 150).

## 4. 결과 상세

### 1부. 이 측정은 믿을 수 있다 (결과 1~2, M0–M1)

- KV 직렬화→복원→이어쓰기: 예측 40/40 동일, 오차는 잡음 수준. 압축 없으면 EM 1.00.
- 질문 KV를 같이 저장하는 실수(V1)는 점수를 4배 부풀림(0.50 vs 0.12) → 전 실험 V2 강제.

### 2부. 실패의 해부 — 문서 도메인 (결과 3~11)

1. **용량 충분**: 질문을 알면 5%로 0.84~0.92, 20%로 0.99. 좋은 부분집합은 존재.
2. **저장 시점 선택 전패**: 최고 대리 지표(s5) 0.61@20% — 천장과 **38%p**.
3. **재사용 붕괴**: 같은 질문 0.99 → 다른 질문 0.59 (40%p; KVzip의 텍스트 35%p와 동규모).
4. **pool 과적합**: 3질문 합집합이 본 질문 0.99, 안 본 질문은 무작위와 동일(0.14@9%).
5. 하나-빼기(LGO)식 중요도는 중복 때문에 거짓말 → 교환 탐색으로 5% 용량 하한 0.92 확인.

### 3부. 3도메인 지도 (결과 12~17)

**거리-유지율 단조 법칙 (★ 이 연구의 법칙)** — 전이 유지율은 두 질문의 근거
중심거리에 단조 감소. GUI 0.765→0.307@5% (+30.6%p [19.2,42.2]),
자연 T2같은답 0.885 / partial 0.714 / T3 0.529 (+35.6%p [24.6,45.3]).

**도메인 3체제 (5% 예산)**:

| | 문서 | GUI | 자연 |
|---|---|---|---|
| 자기 재현−전이 | ~40%p | ~57%p | +23.0%p [17.1,29.3] |
| held-out: pool−random | 0%p (과적합) | **+21.1%p [13.2,29.2]** | +5.9%p (n.s.) |
| random 바닥 (~8–10%) | 0.14 | 0.34 | **0.70** |
| 사다리 승자 | **s5**(범용) 0.611 | **h2o**(이력) 0.725; s5<random −11.2%p | 없음 (전부 random 수준) |
| 천장(s1) 격차 @5% | +38%p | **+54.5%p [49.3,59.7]** | +28.4%p [21.2,35.6] |

**검증 2건 (결과 17)**: ① NO-MEM(질문만) 조건부 0.011/0.043/0.187 — 자연의 높은
바닥은 찍기가 아니라 중복성 (언어 편향 상한 19%p 병기). ② GUI 안에서 근거 분산이
클수록 pool 가치 하락 — Spearman −0.279 [−0.428,−0.122] (독립 표본 중복성 통제;
같은 표본을 겹쳐 쓰면 −0.6짜리 가짜 상관이 나오는 함정도 기록).

### 4부. 방법의 성립 — 감지와 비용 (결과 18·19·21)

**결과 18 (원리)**: 커버리지(질문 attention 중 남긴 조각 비중)가 정답/오답을
AUROC 0.72~0.85로 가려냄. 커버리지 순 폴백은 무작위 폴백을 전 구간 지배 —
GUI 40% 폴백으로 격차 62% 회수 (0.546→0.827).

**결과 19 (비용 실측, V100·batch1)**: 기억 경로 TTFT 0.061s vs 재읽기 1.26s
(**20.5배**). 원본 이미지(127KB)가 5% KV(3.3MB)보다 **27배 작음** → 아카이브
보관은 공짜, KV의 존재 이유는 바이트가 아니라 재계산 시간. 하이브리드는 60%
폴백에서 정확도 0.935를 재읽기 비용의 80%로 달성.

**결과 21 (2a 통과 — 배포형 estimator)**: 전체 KV 없이 계산 가능한 신호 중
**a4 = 첫 답 토큰의 logit 확신도(사후 검증형)**가 4세트 전부 최고:

| a4 AUROC | Q2.5×GUI | Q2.5×자연 | Q3×GUI | Q3×자연 |
|---|---:|---:|---:|---:|
| | **0.809** | **0.732** | **0.733** | **0.809** |

자연에서는 반칙 상한(0.714)마저 초과 — 모델의 머뭇거림이 attention 계산보다 정직.
**임계값 하나**(GUI에서 보정한 τ=1.914)를 다른 모델·도메인에 동결 적용해도 파국
없음(폴백률 28~59% 밴드)이고 네 세트 모두 무작위 폴백 지배, 배포형 하이브리드
0.838 ≈ 반칙 버전 0.827 (**반칙 제거 비용 0**).

**확정된 방법**: 질문 도착 → 저장 조각으로 첫 답 토큰만 생성(0.06s) → 확신도<τ면
원본 이미지 재읽기. 훈련 불필요, 추가 forward 0회, 어떤 압축 위에도 얹히는 wrapper.
안전 비대칭: 판정이 틀려도 최악은 오답이 아니라 불필요한 재읽기.

### 5부. 모델 일반성 (결과 20)

Qwen3-VL-8B(36층·kv8·DeepStack·시각 토큰 1.7배)로 GUI·자연 핵심 3실험 전면 재현:

- 천장 격차 GUI +56.2 [50.8,61.6] (Q2.5 +54.5) / 붕괴 +56.3 [51.1,61.4] /
  단조 +48.9 [40.0,57.8] (더 가파름) / GUI 역전 h2o−s5 +23.6, s5−random −21.1 /
  pool 일반화 +18.4 [9.5,27.2] — **전 항목 같은 방향**.
- 모델이 바꾼 것은 **체제의 경계뿐**: Qwen3는 무작위에 덜 관대(random 바닥
  0.56→0.43)해서 자연에서도 선택·pool이 유의해짐(held-out +20.3 [10.2,30.2]).
  "법칙은 불변, 경계는 모델 따라 이동."
