# GVM 아키텍처 — 게이트형 시각 기억의 2계층 설계도

작성일: 2026-08-20 · 지위: 설계 제안 (각 부품의 검증 상태를 §5에 명시)
근거 데이터: `docs/FINDINGS.md` 결과 1~24, `docs/GATE-VERIFICATION.md`

## 0. 한 문장 요약

VLM 에이전트의 시각 기억을 **세션 안(컨텍스트에 살아 있는 것)과 세션 밖(디스크에 직렬화된 것)의 2계층**으로 나누고, 두 계층 사이의 이동을 **훈련 없는 세 게이트(입력·망각·출력)**가 관리한다. 이미지는 저장물이 아니라 인프라다 — 코덱이 예산을 정하고, 픽셀 대조가 낡음을 잡고, 재지각(re-perception)이 손실을 복구한다.

## 1. 저장 계층 (시스템 관점)

이미지가 모델을 통과하는 각 단계의 산출물이 곧 티어가 된다:

```text
              세션 안 (KV 수명 = 세션)          세션 밖 (byte, 세션 경계를 넘음)
            ┌──────────────────────┐   ┌─────────────────────────────────────┐
 화면 관찰 ─▶│ T0 핫: KV 캐시 (GPU) │   │ T1 웜: 시각 토큰 임베딩 (SSD, 선택) │
            │  · 소모품, 저장 금지  │   │  · KV의 1/8, 무손실, 같은 모델 계열 │
            └──────────┬───────────┘   │ T2 콜드: 압축 이미지 8~32KB (AVIF)  │
                       │ 강등(경계에서) │  · 진실의 원본, 모델 무관           │
                       └──────────────▶│  + 텍스트 색인 ~1.8KB (검색용)      │
                                       └─────────────────────────────────────┘
```

| 티어 | 실체 | 크기(같은 화면) | 정확도(실측) | 재사용 비용 | 이식성 |
|---|---|---|---|---|---|
| T0 KV | 컨텍스트의 어텐션 상태 | 이미지의 27~750배 | (살아있는 동안) 1.0 | 0 | 없음 |
| T1 임베딩 | ViT 인코더 산출 토큰 | KV의 1/8 | KV 지배(무손실) | prefill만 | 같은 계열 |
| T2 이미지 | AVIF/JPEG 파일 | 기준 1× (8~32KB) | 0.951~0.976 | ViT+prefill | 완전 |
| T2 색인 | OCR/요약 텍스트 | ~1.8KB | 단독 0.8(GUI)~붕괴(자연) | 미미 | 완전 |

**설계 원칙 3개 (전부 실측 근거)**
1. **KV는 저장 수단이 아니다** — 질문 도착 전 KV 압축은 원리적 손실(천장 격차 +38~48pp@5%). T0은 세션 안 소모품.
2. **모든 화면은 T2에 무조건 남는다** — 이미지가 진실의 원본. T1은 재사용이 예측될 때만 만드는 속도 옵션.
3. **축출이 아니라 강등** — 컨텍스트가 차면 KV를 버리되 T2 포인터를 남긴다. 필요하면 재지각으로 복원(0.976). "지우면 잃는다"가 아니라 "회상이 비싸질 뿐".

## 2. 이동 정책 = 세 게이트 (시스템 관점)

| 시점 | 게이트 | 판정 재료 (전부 공짜/훈련 불필요) | 행동 |
|---|---|---|---|
| 화면 관찰(write) | **입력** | 코덱 feasibility(압축이 캡에 들어가나) — 시각 복잡도의 무료 측정기 | 화면별 byte 차등 배정(빠듯한 총예산에서 +67%, 오라클 도달), T2 기록, 필요시 T1 |
| 같은 화면 재관찰 | **망각** | 픽셀 타일 대조 30ms — 바뀐 bbox까지 국소화 | 바뀐 영역만 낡음 표시, 새 관찰로 교체. 옛 판은 삭제가 아니라 "이력"으로 강등(시제 질문 대비) |
| 컨텍스트 포화 | (강등) | 오래된/안 쓰인 화면부터 | T0에서 제거 + T2 포인터 유지 |
| 질문 도착(read) | **출력** | 색인 검색 → 답 생성 → a4 확신도(첫 토큰 로짓 마진) | 컨텍스트에 있으면 그대로, 없으면 T1/T2 재주입; 확신도 낮으면 원본 재지각으로 에스컬레이션 (캐스케이드 실측: 격차 50% 회수) |

## 3. 모델링 관점 — 모델은 무엇을 보고, 무엇이 모델에 묶이나

**컨텍스트 직렬화 규약** (실측이 요구하는 것):
```text
[시스템] [기억 블록] [현재 관찰] [질문]
  기억 블록 = { (위치/시각 메타데이터 텍스트 + 이미지) ... }
```
- 메타데이터(관찰 시각·리비전 태그)를 각 이미지 앞에 텍스트로 붙인다. 근거: 옛/새 화면이 병존할 때 모델이 위치 메타데이터를 딛고 100% 최신을 선택(old+current 1.0). 이 규약이 없으면 세션 안 충돌 해소를 보장할 수 없다.
- 반대로 **기억이 하나만 주어지면 모델은 그것이 낡았는지 알 방법이 원리적으로 없다**(조용한 거짓말 48/48, 확신도 무력) — 그래서 낡음 판정은 모델링이 아니라 시스템(망각 게이트)의 책임으로 배치한다. **이 책임 분리가 본 설계의 핵심 주장이다.**

**모델 개입 지점 = 0**: 게이트 신호가 전부 모델 바깥(코덱·픽셀·로짓 마진 읽기)이라 가중치 수정, 미세조정, 추가 헤드가 없다. 2개 모델(Qwen2.5-VL/Qwen3-VL)에서 법칙 재현 — 모델 교체 시 정책이 살아남는 구조.

**모델 종속성 지도** (R2 실측): T2 이미지·색인은 완전 이식 / T1 임베딩은 같은 인코더 계열 내 / T0 KV는 이식 불가. 모델을 업그레이드해도 잃는 것은 T1뿐이고, T2에서 재생성 가능.

**아키텍처 발전과의 관계**: KDA류(채널별 망각을 학습한 선형 어텐션)가 T0을 아무리 효율화해도 세션 경계는 사라지지 않는다 — 본 설계의 T1/T2 정책은 T0 아키텍처와 직교(orthogonal)하며, KDA 하이브리드(싼 감쇠 기억 3 : 정확한 기억 1)는 오히려 같은 게이트 원리가 모델 내부에서도 성립한다는 방증.

**학습형 확장 지점 (선택, 미검증)**: 규칙 게이트가 부족하다고 실측되는 곳에만 국소적으로 학습 게이트를 끼울 수 있다 — 후보: 자연 이미지 입력 신호(오라클 +5.2pp 미실현 구간), 실환경 정렬. 전면 학습(AgeMem식 RL)은 채택하지 않는다: 이득이 완만(+5~8pp급)하고 감사 불가능해지며 모델 종속이 생긴다.
