## 1. 지금 우리가 확보한 것 (팩트)

- **진단(실패 지도)**: "미래 질문을 모르는 채 시각 기억을 5~20%만 남기면 무슨 일이
  생기는가"를 3도메인 × 2모델 × 동결 프로토콜 신규 표본으로 측정 완료.
  핵심 수치: 용량은 충분(질문을 알면 5%로 0.88~0.93) / 어떤 선택 규칙도 천장과
  +26~61%p 격차 / 실패는 근거 이동 거리에 단조 / 도메인·모델 따라 체제 이동.
  **재현 판정 15/15 통과.**
- **감지**: "첫 답 토큰의 확신도"가 실패를 답하기 전에 가려냄 (AUROC 0.73~0.81,
  신규 표본 0.73~0.78). 임계값 하나가 모델·도메인을 건너감.
- **비용 실측**: 원본 이미지(125KB)가 5% KV(3.3MB)의 1/27. KV의 가치는 저장이
  아니라 재계산 생략(첫 토큰 20배 빠름). SSD 로드 40ms(재계산 1260ms 대비).
- **시스템 시제품**: 3단 캐스케이드(옛답 검증→확신 게이트→재읽기)가 신규 화면에서
  격차 50% 회수 + 지연 42% 절감. τ 다이얼로 정확도↔지연 조절 가능.
- 오늘 밤 완료 예정: Qwen3 승격 잔여 + SnapKV/KVzip 원저 비교(3b) + covrisk.

## 2. 외부 검토(gpt.md)의 요지 — 5문장

1. "같은 이미지에 다른 질문" 자체는 novelty가 아니다 — **통제 진단 도구**다.
2. **저장(durable memory)과 캐시(cache)는 다르다.** KV는 이미지보다 27~500배 커서
   저장 수단이 아니고, 가치는 회상 속도뿐. 원본을 폐기 못 하면 "저장 연구"가 아니다.
3. 에이전트 시각 기억 분야가 2025-26년에 빠르게 차고 있다 (아래 §3).
4. 열려 있는 진짜 질문: **"미래를 모르는 에이전트가 시각 경험을 어떤 표현
   (픽셀코덱/텍스트/임베딩/KV)으로, 같은 실제 byte 예산에서 저장해야 하는가"** —
   표현 간 byte-매칭 비교(Representation Frontier)가 결정 실험이다.
5. 현 실험 중 self/cross/held-out·근거이동·byte회계는 유지, draft 캐스케이드는
   분리, 마스킹 시뮬레이션만으로 시스템 주장 금지, R2(세션 이식성) 복원 필요.

## 3. 검토의 신뢰성 검증 (내가 확인한 것)

인용 논문 3건을 검색으로 실재 확인: **VLCache**(같은 입력 재등장 시 전체 캐시 재사용,
TTFT 1.2~16배 — 우리 motivation의 시스템 자리 선점), **TaskMem**(ByteDance, 무엇을
기억할지 학습), **MIRIX**(스크린샷 스트림 구조화 기억). → 검토는 신뢰할 만함.
나머지 6건(PMMC·DMV-Bench 등)은 추가 검증 예정. **단, 확인된 어떤 논문도
"예산 제한 + 미래 비공개 압축의 실패 법칙 + read-시점 감지"는 다루지 않음** —
우리 슬라이스는 아직 비어 있다.

## 4. 검토와 우리 작업의 관계 — 정직한 대차대조

**우리가 이미 스스로 도달했던 것 (검토와 일치)**: KV=소모성 캐시, 이미지=아카이브,
KV 가치=속도뿐, V2 계약, byte 회계, 표현 계층 구상. → 데이터는 전부 유효.

**검토가 맞고 우리가 고칠 것**:
- headline이 "기억 압축"으로 읽힐 여지 → **"예산 제약 캐시의 실패 법칙과 안전화"로
  재조준**, durable-storage 언어 전면 삭제
- 옛답 재활용 캐스케이드는 headline에서 시스템 절로 강등
- 마스킹 시뮬레이션 → 실제 직렬화-복원 경로 검증 1건 추가
- R2(다른 세션·위치로 이식) gate 복원 (인프라 있음, 1일)

**검토 제안 중 이번 논문엔 못 넣는 것**: Representation Frontier 완전판(12표현) —
정직하게 수행하면 4~6주. **최소판(5표현 × 예산 3점)은 1주에 가능.**

## 5. 선택지 — 사용자가 판단할 것

### 선택 1: 논문 프레임 (마감 9/25 ICLR 기준)

| | A안: 진단 논문 (권고) | B안: 시스템 논문 | C안: ICLR 포기, 큰 논문 |
|---|---|---|---|
| 제목 방향 | "A Visual Cache Is Not a Memory" — 실패 법칙 + 감지 + 비용 진실 | 캐스케이드 중심 서빙 시스템 | frontier 완전판 (What Should an Agent Remember?) |
| 근거 데이터 | **지금 확보분으로 거의 완성** | 확보분 + 직렬화 검증 | 4~6주 추가 실험 |
| 위험 | 진단 논문 저평가 리뷰어 | "조립품" 비판 (외부 검토도 지적) | 그 사이 분야가 참 (한 달에 논문 여러 편 페이스) |
| 검토와의 정합 | **검토가 "가장 안정적"이라 지목한 방향** | 검토가 분리 권고한 방향 | 검토의 이상형 |

**내 권고: A안** + frontier 최소판을 §둘째 장에 포함(1주) + 8월 말 arXiv 선공개.
B안 요소(감지·캐스케이드)는 A안의 뒷절로 살리고, C안(frontier 완전판+portfolio
방법)은 2번 논문으로. — 이러면 검토의 권고와 마감이 동시에 충족됨.

### 선택 2: frontier 최소판의 표현 5개 (내 제안)

원본 JPEG / 품질스윕 JPEG / 해상도 축소 / 캡션+OCR 텍스트 / 실제 직렬화 sparse KV
— 예산 32/128/512KiB, held-out 질문 평가. (임베딩 계층은 공학량이 커서 2번 논문으로)

### 선택 3: 자원

- 컨테이너(2×A100): 오늘 밤 완주 후 **반납** vs frontier 최소판까지 며칠 유지(~$50)
- 내 권고: **유지** — frontier와 R2·직렬화 검증이 이번 주에 GPU를 씀
